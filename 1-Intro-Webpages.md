# Intro to Webpages #

### Frontend ###

Web Browser: Reads and renders HTML

JS: Interpreted language (can run interactively)</br>
\- changes the HTML

HTML: Just another way of structuring data (content)</br>
\- Offers interactivity (courtesy of JS)

*understand compiled vs interpreted better*

CSS: Styles data (makes it pretty)

### Backend ###
HTML/CSS/JS/data are loaded in externally (from le internet)</br>
Webpage (client) makes HTTP request for HTML/CSS/JS/data from server</br>

Node.js sits on the server and listens for and processes HTTP requests</br>
\- accesses databases (internal or external)</br>
\- can dynamically generate HTML</br>
Then sends it all back to frontend web browser</br>
