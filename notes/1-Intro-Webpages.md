# Intro to Webpages #

## Frontend ##

Web Browser: Reads and renders HTML

JS: Interpreted language (can run interactively)
\- changes the HTML

HTML: Just another way of structuring data (content)
\- Offers interactivity (courtesy of JS)

*understand compiled vs interpreted better*

CSS: Styles the data

## Backend ##
HTML/CSS/JS/data are loaded in externally (from le internet)
Webpage (client) makes HTTP request for HTML/CSS/JS/data from server

Node.js sits on the server and listens for and processes HTTP requests
\- accesses databases (internal or external)
\- can dynamically generate HTML
Then sends it all back to frontend web browser
