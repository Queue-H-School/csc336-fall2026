# Intro JavaScript

\- server-side runtime progrmaming language</br>
\- web browser acts as a runtime environment (built-in interpreter)</br>
\- loosely typed :(</br>
\- console program is kept in RAM</br>

`console.log(str)` prints a string (echo)</br>
`document.querySelector("h1")` returns the first matching object in HTML doc</br>
`document.querySelectorAll("h1)` returns a NodeList of all matching objects in document</br>

<u>Primitive Types</u></br>
\- number (integer or float)</br>
\- boolean</br>
\- string</br>

<u>Other Types</u></br>
\- arrays</br>
\- objects</br>

<u>Variables</u></br>
\- create (local): `let foo = value`</br>
\- create (local final): `const bar = value`</br>
\- can initialize without value (undefined)</br>
